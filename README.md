# analisis-datos-agricolas
Análisis espacial y estadístico de la producción agrícola en Argentina usando Python (Pandas, Geopandas, Matplotlib). El proyecto integra bases SIG por departamento con datos del MAGyP para evaluar la campaña de soja 2024/25, contrastando el rendimiento agronómico con el financiero mediante la medición de la superficie total perdida.
